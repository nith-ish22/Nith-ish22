# Degree Value Analysis and Automated Reporting

**Individual data analytics and RPA coursework · Singapore Polytechnic ST1510 CA2**

Analysed Singapore graduate employment and salary outcomes to explore how job stability and income potential vary by university degree. Joined two graduate survey datasets by key, cleaned and standardised fields, and compared degree-level outcomes with national employment and income trends from Ministry of Manpower datasets.

## What I built

- A Python analysis pipeline to merge, clean and prepare graduate employment data.
- A weighted comparison index using salary and employment-rate z-scores (60% salary, 40% employment), then grouped results into value tiers.
- Charts for employment and salary trends, the salary-employment trade-off, degree value tiers and salary distributions.
- A UiPath workflow that retrieves the MOM data, runs the analysis, saves seven charts and a summary, then emails the generated report through Outlook.

The weighting is an analytical choice for this coursework, not an official or universal measure of degree value. This portfolio page summarizes the project; module-provided datasets and source submission files are not included.

**Tools:** Python, pandas, data visualisation, UiPath RPA, Excel
