# Green Grass Library Database

An individual database-design coursework project for a fictional library system.

## Design work

The relational model separates membership tiers, members, staff, book titles, physical copies and loan transactions. The schema uses primary and foreign keys to preserve relationships, uniqueness constraints for policy values, and referential actions to protect dependent records.

The SQL work includes queries for borrowing history, repeat borrowing, membership-upgrade eligibility, borrowing limits and issuance checks. The design keeps book metadata separate from physical-copy status to reduce repeated data and support inventory rules.

## Tools and concepts

MySQL · SQL · entity-relationship modelling · normalisation · constraints · joins · aggregation · subqueries

## Scope and data handling

This is a summary of individual coursework.
