# AscendQuest — Gamified Wellness Challenge App

**Individual backend web development coursework · Singapore Polytechnic ST0503 CA2**

AscendQuest is a full-stack wellness app that turns recurring habits into “rituals” and progress into an RPG-style journey. Users can create and track challenges, complete quests, build daily streaks, earn experience and rewards, collect badges, and manage inventory.

## What I built

- Express routes, controllers, and data models for authentication, users, challenges, progress, quests, rewards, and inventory.
- MySQL-backed persistence, with separate modules for database connection and schema/table setup.
- JWT-protected endpoints, password hashing with bcrypt, request validation, and ownership checks for protected challenge actions.
- A browser interface built with HTML, CSS, and vanilla JavaScript that communicates with the backend using Fetch.

## Technical focus

- Structuring a Node.js and Express application into routes, controllers, models, middleware, and services.
- Connecting REST-style APIs to a relational MySQL database.
- Handling authentication and authorization across protected routes.
- Integrating backend features with a client-side interface.

**Tools:** Node.js, Express.js, MySQL, mysql2, JWT, bcryptjs, HTML, CSS, JavaScript
