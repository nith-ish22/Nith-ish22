### DQN control of a pendulum under four gravity settings — group project

Implemented the Deep Q-Network training workflow for a pendulum-control study across default, free-fall, anti-gravity and supergravity conditions. My documented contribution included torque-action discretisation, the Q-network, replay memory, exploration strategy, target-network training, experiment tuning, final training runs and saving the model weights. The project was completed jointly; evaluation and interpretation were shared with a teammate.

**Tools:** Python, TensorFlow/Keras, reinforcement learning

[Project overview](projects/pendulum-dqn/README.md)

### Green Grass Library database — individual coursework

Designed a relational database for a fictional library, separating membership policy, members, staff, titles, physical copies and loans. The work used primary and foreign keys, constraints and SQL queries for borrowing rules and member eligibility. This portfolio page describes the design only; it does not include the coursework dataset or submission files.

**Tools:** MySQL, SQL, ER modelling, database normalisation

[Project overview](projects/library-database/README.md)
